# 考研政治笔记

按"考点地图 → 标记熟/模糊/不会 → 只给模糊点写详细讲解"的方式整理的考研政治笔记。

- `notes/`：笔记源文件（Markdown），按模块分目录
- `pdf/`：生成好的 PDF，直接下载打印
- `style/note.css`：PDF 样式
- `scripts/build.sh`：重新生成全部 PDF（需要 pandoc、node + playwright）
