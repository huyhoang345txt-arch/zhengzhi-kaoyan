## 先看主线：政经其实就是一个故事

::: {.box .flow}
商品（41-44）→ 货币（45）→ 货币变成资本（47）→ 资本生出剩余价值（49-50）→ 剩余价值再变成资本（52）\
→ 资本在流通中转圈（53）→ 剩余价值被瓜分成利润、利息、地租（55-56）→ 自由竞争走向垄断（60-63）
:::

每个考点都是这条链上的一环。读的时候时不时回来看看"我在链条的哪一步"，就不容易乱。

# 第一部分　商品和货币

## [模糊点]{.tag .fuzzy} 41　商品的二因素

::: {.box .core}
**商品**：用来交换的劳动产品。它有两个因素：

- **使用价值**：商品能满足人们某种需要的属性。是**自然属性**，一切有用的东西都有；它构成社会财富的物质内容，是交换价值的物质承担者。
- **价值**：凝结在商品中的**无差别的一般人类劳动**。是**社会属性**，只有商品才有。**交换价值是价值的表现形式**。

**二者是对立统一的关系：**

- **统一**：商品必须同时具有两者，缺一不可。
- **对立**：对同一个人来说，两者不可兼得。卖者要得到价值，就得让出使用价值；买者要得到使用价值，就得付出价值。这个矛盾要靠**交换**来解决。
:::

::: {.box .analogy}
**统计类比：分类变量和数值变量**

- 使用价值像**分类变量**：面包能吃，衣服能穿，它们"质"不同，没法比较谁的使用价值更大。
- 价值像**数值变量**：剥掉所有具体形态以后，都只剩"人类劳动的耗费"，只有多少之分，所以能比较、能交换。

商品交换之所以能按比例进行（1件衣服 = 5个面包），靠的就是价值这个"共同的度量单位"。
:::

::: {.box .trap}
**真题陷阱**

- "有使用价值的东西一定有价值"：**错**。空气、阳光，还有自己种来自己吃的粮食，都有使用价值，但不是商品，没有价值。
- "有价值的东西一定有使用价值"：**对**。没用的东西没人买，劳动就白费了，形不成价值。
- "交换价值就是价值"：**错**。交换价值只是价值的表现形式。
- "价值是商品的自然属性"：**错**，价值是社会属性。
:::

::: {.box .motto}
口诀：**使用价值看"有没有用"，价值看"花了多少劳动"；要卖就得让出用处，要用就得掏出价值。**
:::

## [模糊点]{.tag .fuzzy} 42　劳动二重性

::: {.box .core}
生产商品的劳动有两重属性：

| | 具体劳动 | 抽象劳动 |
|---|---|---|
| 是什么 | 在特定形式下进行的劳动（木匠做桌子、裁缝做衣服） | 撇开具体形式的、无差别的一般人类劳动（体力和脑力的耗费） |
| 产生什么 | **创造使用价值** | **形成价值** |
| 反映什么 | 人和自然的关系（自然属性） | 商品生产者之间的社会关系（社会属性） |

- 这**不是两次劳动**，而是**同一劳动的两个方面**。
- **劳动二重性决定了商品二因素**（具体劳动对应使用价值，抽象劳动对应价值）。
- 劳动二重性学说是**马克思首次提出**的，是**理解政治经济学的枢纽**。
:::

::: {.box .core}
**和第 49 点衔接的一句话，一定要记住：**

在同一个劳动过程中，**具体劳动把生产资料的旧价值转移**到新产品里，**抽象劳动创造新价值**。
:::

::: {.box .trap}
**真题陷阱**

- "劳动是使用价值的唯一源泉"：**错**。使用价值是劳动和自然物质共同创造的（"劳动是财富之父，土地是财富之母"）。
- "价值是由具体劳动创造的"：**错**，价值由抽象劳动形成。
- "抽象劳动是指脑力劳动"：**错**。抽象劳动是撇开具体形式后的人类劳动，体力和脑力都算。
- "劳动二重性是商品二因素决定的"：**错**，因果反了。是劳动二重性**决定**商品二因素。
:::

::: {.box .motto}
口诀：**具体出用处，抽象出价值；具体搬旧值，抽象造新值。**
:::

## [模糊点]{.tag .fuzzy} 43　商品价值量

::: {.box .core}
- 商品的价值量由**社会必要劳动时间**决定，也就是：在现有的社会正常生产条件下，在社会平均的劳动熟练程度和劳动强度下，制造某种使用价值所需要的劳动时间。
- 复杂劳动等于**倍加的简单劳动**，少量复杂劳动等于多量简单劳动。
:::

这个点最常考的是**劳动生产率**和价值量的关系，用这张表一次理清：

| 谁的劳动生产率提高 | 单位商品价值量 | 同一时间内创造的价值总量 | 同一时间内的产量 |
|---|---|---|---|
| **社会**劳动生产率提高 | **下降**（成反比） | **不变** | 增加 |
| **个别**劳动生产率提高 | **不变**（由社会必要劳动时间决定） | **增加**（对这个生产者自己而言） | 增加 |

::: {.box .analogy}
**统计类比：总体均值和个体观测值**

社会必要劳动时间就像**总体均值**，个别劳动时间就像**个体观测值**。商品值多少，看的是总体均值，不看你个人花了多久。

- 你一个人做得快（个体值低于均值），每件商品还是按均值算价值，你单位时间里"赚到"的价值就多。
- 但如果所有人都变快了，总体均值本身就下降了，每件商品的价值也跟着下降。
:::

::: {.box .example}
**例题**　某商品的社会必要劳动时间是 2 小时，1 小时劳动创造的价值折合 10 元。生产者甲 1 小时生产 1 件，一天工作 8 小时。

- **现在**：每件商品价值 20 元（看社会必要劳动时间 2 小时）。甲一天生产 8 件，创造价值 160 元。
- **如果甲自己效率翻倍**（个别劳动生产率提高）：每件商品价值**还是 20 元**；甲一天生产 16 件，创造价值 **320 元**。
- **如果全社会效率翻倍**（社会劳动生产率提高）：社会必要劳动时间变成 1 小时，每件商品价值**降到 10 元**。
:::

::: {.box .trap}
**真题陷阱**

- "个别劳动生产率提高，单位商品价值量降低"：**错**。
- "社会劳动生产率提高，同一时间创造的价值总量增加"：**错**。总量不变，只是分摊到了更多件商品上。
- "商品价值量由生产者个人实际花费的劳动时间决定"：**错**。如果是那样，越懒的人做出的东西反而越值钱。
:::

::: {.box .motto}
口诀：**价值量看社会平均，不看个人；社会变快单价降，个人变快多赚钱。**
:::

## [模糊点]{.tag .fuzzy} 44　私人劳动与社会劳动

::: {.box .core}
- **私人劳动**：在生产资料私有制下，生产什么、生产多少，是生产者自己的事。
- **社会劳动**：因为存在社会分工，每个人的劳动又是社会总劳动的一部分，要满足别人的需要。
- **矛盾在哪**：私人劳动不一定能被社会承认。唯一的办法是**交换**：商品卖出去了，私人劳动才转化成社会劳动。马克思说，商品卖出去是一次"**惊险的跳跃**"，跳不过去，摔坏的是商品生产者自己。
- **地位**：私人劳动和社会劳动的矛盾是**简单商品经济的基本矛盾**。它决定了另外两对矛盾，也决定着商品生产者的命运。
:::

三对矛盾是"一串"的关系：

::: {.box .flow}
私人劳动 ↔ 社会劳动（基本矛盾，决定下面两对）\
具体劳动 ↔ 抽象劳动\
使用价值 ↔ 价值\
商品卖出去了，三对矛盾就一起解决了
:::

::: {.box .trap}
**真题陷阱**

两个"基本矛盾"别混：

| | 基本矛盾 |
|---|---|
| **简单商品经济** | 私人劳动和社会劳动的矛盾 |
| **资本主义社会** | 生产社会化和生产资料资本主义私人占有之间的矛盾 |

- "简单商品经济的基本矛盾是使用价值和价值的矛盾"：**错**。
:::

## [模糊点]{.tag .fuzzy} 45　货币的本质与职能

::: {.box .core}
**货币怎么来的**：价值形式经历了四个阶段，简单的（偶然的）价值形式 → 扩大的价值形式 → 一般价值形式 → **货币形式**。货币是商品交换长期发展的产物。

**货币的本质**：**固定充当一般等价物的商品**，它体现的是商品生产者之间的社会关系。
:::

**五种职能**，其中价值尺度和流通手段是**基本职能**：

| 职能 | 做什么 | 关键细节 | 生活中的例子 |
|---|---|---|---|
| **价值尺度** | 衡量商品价值的大小 | 只需要**观念上**的货币 | 手机**标价** 3000 元 |
| **流通手段** | 充当商品交换的媒介 | 必须是**现实**的货币，但可以是不足值的、纸币 | **一手交钱一手交货**买下手机 |
| **贮藏手段** | 退出流通，被保存起来 | 必须是**现实的、足值的**金属货币 | 把金银收藏起来 |
| **支付手段** | 清偿债务、缴税、发工资、付租金 | 是价值的**单方面转移**，和商品流通在时间上分离 | 月底**发工资**、**分期付款**、**交税** |
| **世界货币** | 在世界市场上充当一般等价物 | | 国际结算 |

::: {.box .core}
**货币流通规律**（可能出计算题）：

流通中所需要的货币量 = 商品价格总额 ÷ 货币流通速度

如果考虑赊销：所需货币量 =（商品价格总额 − 赊销商品价格总额 + 到期支付总额 − 相互抵消的支付总额）÷ 货币流通速度

**纸币**是国家发行、强制使用的价值符号，它的发行量应当以流通中所需要的金属货币量为限度。发多了，就会通货膨胀。
:::

::: {.box .trap}
**真题陷阱**

- 区分"流通手段"和"支付手段"是最常考的：**钱货同时易手**是流通手段；**钱和货在时间上分开**（发工资、还贷款、交房租、赊购后付款）是支付手段。
- "标价"用的是价值尺度，只要观念上的货币就够了，不需要真有钱在手里。
- "货币是一般等价物"：**不准确**，要说"**固定**充当一般等价物"。在货币出现之前，一般价值形式里已经有一般等价物了，只是不固定。
:::

# 第二部分　剩余价值

## [模糊点]{.tag .fuzzy} 49　不变资本与可变资本

::: {.box .core}
**划分依据**：资本各部分在**剩余价值生产中的作用不同**。

- **不变资本 c**：以生产资料形式存在的资本（厂房、机器、原材料）。在生产中，它的价值通过工人的具体劳动**转移**到新产品里，**价值量不变**。
- **可变资本 v**：用来购买劳动力的资本。工人在生产中**创造出新价值（v + m）**，比劳动力本身的价值大，**价值量发生了变化**。

商品价值 = **c + v + m**

**意义**：揭示了**剩余价值的真正来源是可变资本**（准确说是雇佣工人的剩余劳动），而不是全部资本；也为确定资本家对工人的剥削程度提供了科学依据。
:::

::: {.box .trap}
**真题陷阱**

**① 和"固定资本 / 流动资本"的划分混在一起考**（第 53 点）：

| | 不变资本 / 可变资本 | 固定资本 / 流动资本 |
|---|---|---|
| 划分依据 | 在剩余价值生产中的**作用** | 价值的**周转方式** |
| 意义 | 揭示剩余价值的来源 | 影响资本周转速度 |
| 机器、厂房 | 不变资本 | 固定资本 |
| **原材料** | **不变资本** | **流动资本** |
| 劳动力（工资） | 可变资本 | 流动资本 |

原材料是最常见的坑：它**既是不变资本，又是流动资本**。

**② 机器和人工智能**

- "机器 / 机器人 / 人工智能创造剩余价值"：**错**。它们是生产资料，属于不变资本，只转移自身的价值，不创造新价值。
- 用了先进机器的企业利润更高，是因为个别劳动生产率提高，获得了**超额剩余价值**（第 50 点），来源还是工人的剩余劳动。
:::

::: {.box .motto}
口诀：**c 只搬家不增值，v 会下蛋生出 m；原料一身两个名，不变又流动。**
:::

## [模糊点]{.tag .fuzzy} 50　剩余价值率与两种生产方法

::: {.box .core}
**工作日 = 必要劳动时间 + 剩余劳动时间**

- 必要劳动时间：工人再生产劳动力价值（v）的时间。
- 剩余劳动时间：工人为资本家无偿生产剩余价值（m）的时间。

**剩余价值率 m′ = m ÷ v = 剩余劳动时间 ÷ 必要劳动时间**，反映资本家对工人的剥削程度。
:::

| | 绝对剩余价值 | 相对剩余价值 |
|---|---|---|
| 怎么做到 | 必要劳动时间不变，**延长工作日**（或提高劳动强度） | 工作日不变，**缩短必要劳动时间** |
| 前提 | 无 | **全社会**劳动生产率提高，生活资料变便宜，劳动力价值下降 |

::: {.box .core}
**超额剩余价值**：个别企业的劳动生产率**高于社会平均水平**，商品的个别价值低于社会价值，却按社会价值出售，于是多得的那部分剩余价值。

- 它是个别资本家改进技术的**直接动机**。
- 大家都去追求超额剩余价值，全社会劳动生产率就提高了，结果是**相对剩余价值**普遍产生。
- 超额剩余价值是**相对剩余价值的变形**。
:::

::: {.box .analogy}
**统计类比：领先者红利**

超额剩余价值，就像你的个体值低于总体均值时得到的"领先红利"。可是当所有人都追上来，总体均值下降，你的红利就没了，变成了大家都有的"相对剩余价值"。
:::

::: {.box .example}
**例题**　工作日 8 小时，必要劳动时间 4 小时。

- 原来：m′ = 4 ÷ 4 = **100%**
- **绝对剩余价值**：工作日延长到 10 小时，必要劳动时间还是 4 小时 → m′ = 6 ÷ 4 = **150%**
- **相对剩余价值**：工作日还是 8 小时，社会劳动生产率提高，必要劳动时间缩短到 2 小时 → m′ = 6 ÷ 2 = **300%**

**另一种问法**：资本家雇工人付工资 2000 元，工人创造的新价值是 6000 元 → m = 6000 − 2000 = 4000 元，m′ = 4000 ÷ 2000 = **200%**。
注意：**新价值是 v + m**，不包括 c。
:::

::: {.box .trap}
**真题陷阱**

- "剩余价值率 = m ÷ (c + v)"：**错**，那是利润率（第 55 点）。
- "相对剩余价值是个别资本家提高劳动生产率的结果"：**错**。是**全社会**劳动生产率提高的结果；个别企业提高，得到的是**超额**剩余价值。
- "超额剩余价值来源于先进的机器设备"：**错**。来源仍是工人的剩余劳动。
:::

::: {.box .motto}
口诀：**拉长工作日叫绝对，压短必要时间叫相对；一家先进得超额，家家先进变相对。**
:::

# 第三部分　资本积累、流通和分配

## [模糊点]{.tag .fuzzy} 52　资本积累与资本有机构成

::: {.box .core}
- **资本积累**：把剩余价值转化为资本，用来扩大再生产。**剩余价值是资本积累的唯一源泉**，资本积累又是扩大再生产的源泉。
- **动因**：内在动力是追求剩余价值，外在压力是竞争。
- **积累规模取决于**：对工人的剥削程度、劳动生产率的高低、所用资本和所费资本之间差额的大小、预付资本量的大小。
:::

::: {.box .core}
**资本有机构成**：由资本技术构成决定、并反映技术构成变化的资本价值构成，用 **c : v** 表示。

- 技术构成：生产资料和劳动力之间的**数量**比例（多少台机器配多少个工人）。
- 价值构成：不变资本和可变资本之间的**价值**比例（c : v）。

随着资本积累，资本有机构成有**不断提高**的趋势：机器越来越多，买劳动力的钱占比越来越小。
:::

**资本积累带来两个后果：**

1. **相对过剩人口**：资本有机构成提高，资本对劳动力的需求**相对减少**；同时劳动力供给增加。于是一部分工人失业，形成产业后备军。"相对"的意思是，相对于资本增殖的需要来说多余，不是人口绝对太多。
2. **两极分化**：一极是财富的积累，另一极是贫困的积累。这是**资本主义积累的一般规律**。

::: {.box .example}
**例题：为什么资本翻倍了，就业却不增加**

- 原来：总资本 100 万，c : v = 4 : 1 → c = 80 万，v = 20 万。
- 积累之后：总资本 200 万，c : v = 9 : 1 → c = 180 万，v = **20 万**。

资本翻了一倍，用来雇工人的钱却一分没多，劳动力需求**相对**下降了，这就是相对过剩人口的来源。
:::

::: {.box .trap}
**真题陷阱**

- "相对过剩人口是人口增长太快造成的"：**错**。这是马尔萨斯的观点；马克思认为根源在于资本积累和有机构成提高。
- 区分**资本积聚**和**资本集中**：

| | 资本积聚 | 资本集中 |
|---|---|---|
| 怎么来 | 靠**积累**剩余价值，个别资本自己变大 | 靠**竞争和信用**，把多个资本**合并**成大资本 |
| 社会资本总额 | **增加** | **不增加**，只是重新组合 |
| 速度限制 | 受社会财富增长速度限制，较慢 | 不受这个限制，可以很快 |
:::

## [模糊点]{.tag .fuzzy} 53　资本循环与周转

::: {.box .core}
**资本循环：三个阶段，三种职能形式**

| 阶段 | 过程 | 资本形式的变化 |
|---|---|---|
| 购买阶段 | 用钱买生产资料和劳动力 | 货币资本 → 生产资本 |
| 生产阶段 | 生产出包含剩余价值的商品 | 生产资本 → 商品资本 |
| 售卖阶段 | 把商品卖掉 | 商品资本 → 货币资本（多了 m） |

循环要连续进行，三种职能形式必须在**空间上并存**（保持比例），在**时间上继起**（一个接一个地转化）。
:::

::: {.box .core}
**资本周转**：周而复始、不断重复的资本循环。

- 周转时间 = 生产时间 + 流通时间
- 年周转次数 **n = 12 个月 ÷ 周转一次所需的月数**
- **固定资本**（厂房、机器）：价值**逐渐地、分多次**转移到产品里；**流动资本**（原材料、劳动力）：价值**一次全部**转移，一次收回。
- **加快周转的好处**：预付同样多的可变资本，一年里能多次发挥作用，**年剩余价值量和年剩余价值率都会提高**。
:::

::: {.box .core}
**两个计算公式：**

- 年剩余价值率 **M′ = m′ × n**；年剩余价值量 **M = m′ × v × n**
- 预付资本总周转次数 =（固定资本年周转价值总额 + 流动资本年周转价值总额）÷ 预付总资本
:::

::: {.box .example}
**例题 1**　预付可变资本 10 万元，m′ = 100%，资本周转一次需要 3 个月。

n = 12 ÷ 3 = 4 次；M′ = 100% × 4 = **400%**；年剩余价值量 M = 100% × 10 万 × 4 = **40 万元**。

**例题 2**　预付总资本 100 万元：固定资本 80 万元，可用 10 年；流动资本 20 万元，一年周转 5 次。

- 固定资本一年周转的价值 = 80 ÷ 10 = 8 万
- 流动资本一年周转的价值 = 20 × 5 = 100 万
- 总周转次数 =（8 + 100）÷ 100 = **1.08 次**
:::

::: {.box .trap}
**真题陷阱**

- "原材料属于固定资本"：**错**，属于流动资本（同时也是不变资本，见第 49 点的表）。
- "劳动力属于不变资本 / 固定资本"：**错**，它是可变资本，也是流动资本。
- "加快资本周转能提高剩余价值率 m′"：**不准确**。提高的是**年**剩余价值率 M′，每次周转的 m′ 不变。
:::

## [模糊点]{.tag .fuzzy} 55　利润、平均利润与生产价格

先看一条转化链，这一节讲的就是它：

::: {.box .flow}
剩余价值 m → 利润 → 平均利润\
商品价值 → 生产价格
:::

::: {.box .core}
**第一步：剩余价值变成利润**

- **成本价格 k = c + v**（资本家眼里的"成本"），商品价值 W = k + m。
- 剩余价值被看成**全部预付资本**带来的，就变成了**利润**。利润是剩余价值的**转化形式**，它**掩盖了剥削**（其实 m 只来自 v）。
- **利润率 p′ = m ÷ (c + v)**，它总是小于剩余价值率 m′。

**第二步：利润变成平均利润**

- 不同部门的资本有机构成不同，利润率也就不同。资本会从利润率低的部门流向高的部门，通过竞争，各部门的利润率趋于平均，形成**平均利润率**。
- 平均利润 = 预付资本 × 平均利润率
- **本质**：整个资本家阶级按资本大小**瓜分**剩余价值，这进一步掩盖了剥削。

**第三步：价值变成生产价格**

- **生产价格 = 成本价格 + 平均利润**
- 从此以后，市场价格**围绕生产价格**上下波动。
- **这不违背价值规律**：就全社会来说，利润总额 = 剩余价值总额，生产价格总额 = 价值总额。
:::

::: {.box .analogy}
**统计类比：加权平均和回归均值**

平均利润率其实就是**按资本量加权的平均值**。资本在各部门之间流动，就像在不断"再抽样"，最后让每一份资本都拿到差不多的回报，利润率回归到均值。
:::

::: {.box .example}
**例题**　两个部门各预付资本 100，剩余价值率都是 100%。

| | c | v | m | 价值 W | 利润率 | 平均利润 | 生产价格 |
|---|---|---|---|---|---|---|---|
| 甲部门 | 80 | 20 | 20 | 120 | 20% | 30 | **130** |
| 乙部门 | 60 | 40 | 40 | 140 | 40% | 30 | **130** |
| 合计 | | | 60 | 260 | 平均 **30%** | 60 | 260 |

平均利润率 =（20 + 40）÷（100 + 100）= 30%。
甲部门的生产价格高于它的价值，乙部门的生产价格低于它的价值，但**两边加总，正好相等**。
:::

::: {.box .trap}
**真题陷阱**

- "利润来源于全部预付资本"：**错**，这只是表面现象，利润的真正来源是可变资本带来的剩余价值。
- "生产价格形成以后，价值规律不起作用了"：**错**，只是价值规律作用的**形式**变了。
- "利润率就是 m ÷ v"：**错**，m ÷ v 是剩余价值率。
:::

::: {.box .motto}
口诀：**m 看成全部资本生的就叫利润，利润一平均就成平均利润；成本加平均利润是生产价格，加总还是等于价值。**
:::

## [模糊点]{.tag .fuzzy} 56　商业利润、利息、地租

::: {.box .core}
**一句话总纲：三者都是剩余价值的转化形式，都来自雇佣工人在生产领域创造的剩余价值。** 剩余价值只在生产中产生，流通中不产生。
:::

| 收入 | 谁拿到 | 本质和来源 |
|---|---|---|
| **商业利润** | 商业资本家 | 产业资本家让渡给商业资本家的一部分剩余价值。商业资本家以低于生产价格的价格从产业资本家那里买进，再按生产价格卖出 |
| **利息** | 借贷资本家 | 借钱的职能资本家，从自己获得的平均利润里分出一部分给借贷资本家。利息率在 0 和平均利润率之间 |
| **银行利润** | 银行资本家 | 贷款利息 − 存款利息 − 银行业务费用，大体相当于平均利润 |
| **股息** | 股票持有者 | 来源于剩余价值 |
| **地租** | 土地所有者 | 农业资本家缴给土地所有者的、**超过平均利润的那部分剩余价值**，来源是农业工人创造的剩余价值 |

::: {.box .core}
**地租分两种：**

- **级差地租**：因为土地的肥沃程度、地理位置、追加投资不同而产生。原因是土地有限，经营上有垄断。
- **绝对地租**：不管租的是好地还是坏地都得交。原因是**土地私有权的垄断**。

**两个价格公式（都是"收入 ÷ 利息率"）：**

- **股票价格 = 预期股息 ÷ 银行利息率**
- **土地价格 = 地租 ÷ 银行利息率**
:::

::: {.box .analogy}
**统计类比：永续年金的现值**

股票价格和土地价格的公式，其实就是**永续年金的现值公式 PV = C ÷ r**。买一块地，相当于买下了"每年收一笔地租"的权利；它值多少钱，就看这笔钱存银行要多少本金才能每年拿到同样的利息。
:::

::: {.box .example}
**例题**　一块地每年地租 2 万元，银行年利率 4%，土地价格 = 2 ÷ 4% = **50 万元**。
如果利率降到 2%，土地价格就涨到 **100 万元**。利率越低，地价越高。
:::

::: {.box .trap}
**真题陷阱**

- "利息是货币自己生出来的"：**错**，来源是剩余价值。
- "地租来源于土地本身的肥力"：**错**。土地肥沃只是产生级差地租的**条件**，地租的来源是农业工人的剩余劳动。
- "商业利润是商业资本家贱买贵卖、在流通中赚来的"：**错**。流通领域不创造剩余价值。
:::

# 第四部分　垄断资本主义

## [模糊点]{.tag .fuzzy} 60　垄断利润与垄断价格

::: {.box .core}
- **垄断利润**：垄断资本家凭借垄断地位，获得的**超过平均利润**的高额利润。
- **来源**：说到底仍然是劳动者创造的价值，具体包括：
  1. 垄断企业工人创造的剩余价值；
  2. 非垄断企业工人创造的一部分剩余价值；
  3. 小生产者创造的一部分价值；
  4. 通过不等价交换、资本输出，从国外劳动人民那里获得的一部分剩余价值和价值；
  5. 通过国家财政再分配，把劳动人民的一部分收入转为垄断利润。
- **实现形式**：**垄断价格 = 成本价格 + 垄断利润**。垄断组织卖东西时用垄断高价，买东西时用垄断低价。
:::

::: {.box .core}
**垄断价格为什么不否定价值规律？**

- 垄断价格**没有增加整个社会的价值总量**，只是把价值和剩余价值**重新分配**了：垄断组织多得的那部分，就是别人少得的那部分。
- 全社会的商品价格总额，仍然等于价值总额。
- 变的只是价值规律**作用的表现形式**。
:::

价值规律在三个阶段的"表现形式"，串起第 46、55、60 三个点：

| 阶段 | 市场价格围绕什么波动 |
|---|---|
| 简单商品经济 | **价值** |
| 自由竞争资本主义 | **生产价格**（成本价格 + 平均利润） |
| 垄断资本主义 | **垄断价格**（成本价格 + 垄断利润） |

::: {.box .trap}
**真题陷阱**

- "垄断价格否定了价值规律"：**错**。
- "垄断利润来源于垄断本身 / 来源于流通领域"：**错**，来源是劳动者创造的价值。
- 第 59 点顺带记住："垄断消除了竞争"：**错**。垄断没有消除竞争，反而让竞争更加激烈、更加复杂。
:::

## [模糊点]{.tag .fuzzy} 61　金融资本与金融寡头

::: {.box .core}
- 银行业也出现垄断以后，银行的作用变了：从普通的支付中介，变成了**万能的垄断者**。
- **金融资本**：**工业垄断资本**和**银行垄断资本**融合在一起形成的垄断资本。
- **金融寡头**：操纵国民经济命脉、实际上控制着国家政权的少数垄断资本家或垄断资本家集团。
:::

金融寡头靠两种手段实现统治，**一经济，一政治，不能混**：

| | 经济上 | 政治上 |
|---|---|---|
| 手段 | **参与制** | **个人联合** |
| 怎么做 | 掌握一定数量的股票就能控股，形成"母公司 → 子公司 → 孙公司"的层层控制 | 和政府相互渗透：派代理人进入政府，或者让政府高官到垄断企业任职 |

::: {.box .example}
**参与制为什么厉害：用小资本控制大资本**

假设控股只需要 50% 的股份。金融寡头用 1 亿控制一家 2 亿规模的母公司；母公司再用 1 亿控制一家 2 亿规模的子公司……每多一层，控制的资本规模就继续扩大，像金字塔一样层层放大。
:::

::: {.box .trap}
**真题陷阱**

- "参与制"和"个人联合"互换，比如说"金融寡头通过参与制实现政治统治"：**错**。
- "金融资本就是银行资本"：**错**，是工业垄断资本和银行垄断资本的**融合**。
:::

::: {.box .motto}
口诀：**经济靠参股，层层往下控；政治靠联合，人员互相通。**
:::

## [模糊点]{.tag .fuzzy} 62　国家垄断资本主义

::: {.box .core}
- **定义**：国家政权和私人垄断资本融合在一起的垄断资本主义。
- **产生原因**：根源是生产社会化和资本主义私人占有之间矛盾的发展。具体来说：大型项目和基础设施投资巨大，私人垄断资本无力承担；市场问题越来越严重，需要国家来扩大需求；社会经济结构失衡、科技发展带来的问题，需要国家来调节。
- **主要形式**：
  1. 国家所有并直接经营企业；
  2. 国家与私人共有、合营企业；
  3. 国家通过订货、投资补贴、贷款担保等方式，参与私人垄断资本的再生产；
  4. 国家通过财政政策、货币政策等，对经济进行宏观调节。
:::

::: {.box .core}
**实质和作用：一分为二地看**

- **实质**：私人垄断资本**利用国家机器**来干预经济，目的是保证垄断资本获得高额利润。
- **积极作用**：在一定程度上**缓和**了资本主义的基本矛盾，对经济发展有一定的促进作用。
- **局限**：没有改变资本主义私有制的性质，也没有改变雇佣劳动的剥削关系，**不能从根本上解决**资本主义的基本矛盾。
:::

::: {.box .trap}
**真题陷阱**

- "资本主义国家的国有企业具有社会主义性质"：**错**。它是为总垄断资本服务的，属于资本主义性质。
- "国家垄断资本主义消除了经济危机 / 解决了资本主义基本矛盾"：**错**，只是**缓和**了。
- "国家垄断资本主义改变了资本主义的性质"：**错**。
:::

::: {.box .motto}
口诀：**国家和垄断资本拧成一股绳；能缓和矛盾，不能根治，本质还是资本主义。**
:::

## [模糊点]{.tag .fuzzy} 63　资本输出与经济全球化

::: {.box .core}
**资本输出**

- **原因**：垄断资本主义国家出现了大量"**过剩资本**"。这里的"过剩"是**相对**的，指在国内找不到能获得高额利润的投资场所，不是资本绝对太多。
- **形式**：按形式分，有借贷资本输出、生产资本输出（直接投资办厂）；按来源分，有私人资本输出、国家资本输出。
- **实质**：垄断资本向国外扩张、获取高额垄断利润的手段。对资本输入国的影响是**双重的**：带来资金和技术，也带来控制和利润外流。
:::

::: {.box .core}
**国际垄断同盟**：从国际卡特尔，发展到**跨国公司**（现代最主要的形式），再发展到国家垄断资本的国际联盟（比如欧盟这样的区域经济一体化组织）。
:::

::: {.box .core}
**经济全球化**

- **表现**：国际分工进一步深化；贸易全球化；金融全球化；企业生产经营全球化。
- **动因**：科技进步和生产力发展是根本的推动力；跨国公司的发展是重要推动者；各国经济体制的变革（普遍走向市场经济）提供了制度条件。
- **后果是一把"双刃剑"**：一方面促进资源在全球优化配置，给发展中国家带来机遇；另一方面，当前的经济全球化主要由发达资本主义国家主导，南北差距可能扩大，经济风险也更容易在各国之间传导。
- **中国的主张**：推动建设开放型世界经济，推动经济全球化朝着更加开放、包容、普惠、平衡、共赢的方向发展。
:::

::: {.box .trap}
**真题陷阱**

- "资本输出是因为国内资本绝对过剩"：**错**，是相对过剩。
- "经济全球化就是资本主义化 / 西方化"：**错**。
- "经济全球化对发展中国家只有好处 / 只有坏处"：**错**，是双刃剑。
:::

# 第五部分　三星高频点速览

## [高频]{.tag .hot} 64　二战后资本主义的新变化

::: {.box .core}
**五个方面的变化：**

1. **生产资料所有制**：国家资本所有制形成和发展，**法人资本所有制**崛起，并成为垄断资本所有制的主要形式；股权分散化，出现职工持股。
2. **劳资关系和分配关系**：职工参与企业决策，终身雇佣，职工持股；建立社会福利制度。
3. **社会阶层和阶级结构**：资本家的地位和作用发生变化，高级职业经理人成为大公司的实际管理者；知识型、技术型的劳动者增加。
4. **经济调节机制和经济危机形态**：国家对经济的干预加强。
5. **政治制度**：政治制度出现多元化趋势，法制建设不断加强。

**变化的原因**：科技革命和生产力的发展（根本推动力）；工人阶级斗争的结果；社会主义制度的影响；主张改良主义的政党的作用。

**实质**：这些都是在**资本主义制度框架内**的调整，**没有改变**资本主义私有制和雇佣劳动剥削的**本质**。
:::

::: {.box .trap}
- "当代资本主义已经变成'人民资本主义'，私有制消失了"：**错**。
- "职工持股使工人变成了资本家"：**错**。职工持有的股份很少，改变不了雇佣劳动的地位。
:::

# 公式一页纸

| 公式 | 内容 | 对应考点 |
|---|---|---|
| 单位商品价值量 | 与**社会**劳动生产率成反比，与个别劳动生产率无关 | 43 |
| 流通中所需货币量 | 商品价格总额 ÷ 货币流通速度 | 45 |
| 商品价值 | W = c + v + m；其中新价值 = v + m | 49 |
| 剩余价值率 | m′ = m ÷ v = 剩余劳动时间 ÷ 必要劳动时间 | 50 |
| 资本有机构成 | c : v | 52 |
| 年周转次数 | n = 12 ÷ 周转一次所需的月数 | 53 |
| 年剩余价值率 | M′ = m′ × n | 53 |
| 年剩余价值量 | M = m′ × v × n | 53 |
| 预付资本总周转次数 | （固定资本年周转价值 + 流动资本年周转价值）÷ 预付总资本 | 53 |
| 成本价格 | k = c + v | 55 |
| 利润率 | p′ = m ÷ (c + v) | 55 |
| 平均利润 | 预付资本 × 平均利润率 | 55 |
| 生产价格 | 成本价格 + 平均利润 | 55 |
| 股票价格 | 预期股息 ÷ 银行利息率 | 56 |
| 土地价格 | 地租 ÷ 银行利息率 | 56 |
| 垄断价格 | 成本价格 + 垄断利润 | 60 |

::: {.box .trap}
**最容易算错的三处**

1. 剩余价值率的分母是 **v**，利润率的分母是 **c + v**。
2. "新创造的价值"是 **v + m**，不包括 c。
3. 年剩余价值率要乘以**周转次数 n**，每次周转的 m′ 本身不变。
:::
