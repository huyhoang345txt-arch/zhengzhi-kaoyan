# 第一部分　你的 5 个模糊点

## [模糊点]{.tag .fuzzy} 1　马克思主义的鲜明特征

::: {.box .core}
**四个特征：科学性、人民性、实践性、发展性。**

- **科学性**：马克思主义是科学的理论，以实践为基础，揭示了自然界、人类社会和人类思维发展的普遍规律。
- **人民性**：马克思主义是人民的理论，第一次创立了人民实现自身解放的思想体系。**人民性是马克思主义的本质属性。**
- **实践性**：马克思主义是实践的理论，指引人民改造世界。**实践性是马克思主义区别于其他理论的显著特征。**
- **发展性**：马克思主义是不断发展的开放的理论，始终站在时代前沿。
:::

::: {.box .analogy}
**统计类比：一个好模型的四个标准**

- 科学性：模型确实抓住了数据背后的规律，不是硬凑出来的。
- 人民性：这个模型为谁服务，解决的是谁的问题。这是它的"立场"。
- 实践性：模型要拿来解决真实问题，并且接受实际数据的检验。
- 发展性：来了新数据就要更新模型，不能一成不变。
:::

单选最爱考"**最 / 本质 / 显著**"这类定位词，下面这张表一定要对上号：

| 题干说法 | 对应答案 |
|---|---|
| 马克思主义的**本质属性** | 人民性 |
| 区别于其他理论的**显著特征** | 实践性 |
| 马克思主义**最鲜明的政治立场** | 致力于实现以劳动人民为主体的最广大人民的根本利益 |
| 马克思主义**最重要的理论品质** | 坚持一切从实际出发，理论联系实际，实事求是，在实践中检验真理和发展真理 |
| 马克思主义**最崇高的社会理想** | 实现物质财富极大丰富、人民精神境界极大提高、每个人自由而全面发展的共产主义社会 |

::: {.box .trap}
**真题陷阱**

- "本质属性"和"显著特征"互换，比如说成"实践性是本质属性"：**错**。
- 说"马克思主义是一成不变的真理体系"：违背发展性，**错**。
- 说"马克思主义的科学性和人民性是对立的"：**错**。两者是统一的，科学性保证它说得对，人民性决定它为谁说话。
:::

::: {.box .motto}
口诀：**人民是本质，实践最显著；科学讲规律，发展不停步。**
:::

::: {.box .quiz}

A. 科学性　B. 人民性　C. 实践性　D. 发展性

**自测 1-2**　"马克思主义是不断发展的开放的理论，始终站在时代前沿"，体现的是马克思主义的（　）\
A. 科学性　B. 人民性　C. 实践性　D. 发展性

**自测 1-3**　判断：人民性是马克思主义区别于其他理论的显著特征。（　）
:::

## [模糊点]{.tag .fuzzy} 3　哲学基本问题

::: {.box .core}
**哲学的基本问题 = 思维和存在的关系问题**（也就是意识和物质的关系）。它分成两个方面：

1. **谁是第一性？** 存在（物质）第一 → **唯物主义**；思维（意识）第一 → **唯心主义**。
   这是划分唯物主义和唯心主义的**唯一标准**。
2. **思维能不能认识存在？**（思维和存在有没有同一性）能 → **可知论**；不能 → **不可知论**。

为什么说它是"基本问题"？因为任何哲学都绕不开它，而且怎么回答它，决定了一种哲学的性质和方向。
:::

**唯物主义和唯心主义各自分哪几种？** 单选常让你给一句古话"站队"：

| 派别 | 观点 | 典型说法 |
|---|---|---|
| 主观唯心主义 | 把**个人的感觉、意识**当作世界的本原 | "存在就是被感知"（贝克莱）、"心外无物"（王阳明） |
| 客观唯心主义 | 把**某种客观精神**当作世界的本原 | "理在事先"（朱熹）、"绝对精神"（黑格尔） |
| 古代朴素唯物主义 | 把物质归结为**某种具体物质形态** | 水、火、原子、"五行"、"气" |
| 近代形而上学唯物主义 | 物质 = **原子**，用机械的、孤立的眼光看世界 | 一到社会历史领域就滑向唯心主义（不彻底） |
| 辩证唯物主义 | 物质的唯一特性是客观实在性 | 马克思主义哲学 |

::: {.box .analogy}
**统计类比：第二个方面就像"能不能从样本推断总体"**

- 可知论：样本越来越多，对总体的估计就能越来越接近真相。世界上只有**还没认识的**东西，没有**不能认识的**东西。
- 不可知论（休谟、康德）：我们永远只能看到"样本"，也就是现象，背后的"总体"（康德叫"物自体"）永远不可能知道。
:::

::: {.box .trap}
**真题陷阱**

- **可知论不一定是唯物主义。** 黑格尔是客观唯心主义者，但他认为思维能认识存在，所以他是可知论者。第一个方面决定唯物还是唯心，第二个方面决定可知还是不可知，两个方面要**分开判断**。
- "辩证法和形而上学的对立"**不是**哲学基本问题。那是"世界是联系发展的，还是孤立静止的"，属于另一对范畴。
- 判断唯物还是唯心，只看第一个方面。用"能不能认识世界"来划分：**错**。
:::

::: {.box .motto}
口诀：**谁先谁后分唯物唯心，能不能认识分可知不可知，两把尺子各量各的。**
:::

::: {.box .quiz}
**自测 3-1**　"存在就是被感知"属于（　）\
A. 客观唯心主义　B. 主观唯心主义　C. 朴素唯物主义　D. 不可知论

**自测 3-2**　判断：凡是承认世界可知的哲学，都是唯物主义哲学。（　）

**自测 3-3**（多选）哲学基本问题包括（　）\
A. 思维和存在何者为第一性　B. 思维能否正确认识存在\
C. 世界是联系发展的还是孤立静止的　D. 人能否改造世界
:::

## [模糊点]{.tag .fuzzy} 10　联系的特点

::: {.box .core}
**联系**：事物内部各要素之间、事物之间相互影响、相互制约、相互作用的关系。
联系有四个特点：**客观性、普遍性、多样性、条件性**。
:::

| 特点 | 意思 | 必须记住的那句话 |
|---|---|---|
| **客观性** | 联系是事物本身固有的，不以人的意志为转移 | 人**不能创造联系**，但可以根据事物固有的联系，**改变事物的状态，建立新的具体联系**。人为建立的联系，本身也是客观的 |
| **普遍性** | 事物内部各要素相互联系；任何事物都与周围其他事物相互联系；整个世界是一个相互联系的统一整体 | 普遍联系**不是说**任何两个事物之间都有**直接**联系 |
| **多样性** | 直接联系与间接联系、内部联系与外部联系、本质联系与非本质联系、必然联系与偶然联系…… | 所以要**具体分析**每一种联系 |
| **条件性** | 条件对事物发展和人的活动有支持或制约作用 | 条件可以改变，人可以**改变和创造条件**，但必须尊重客观规律，不能随心所欲 |

::: {.box .analogy}
**统计类比：伪相关**

冰淇淋销量和溺水人数正相关，这个联系是真实存在的（**客观性**），但它是通过"气温"这个中间变量形成的**间接联系**，不是直接因果关系（**多样性**）。
你做实验、控制变量，就是在"改变条件"、"建立新的具体联系"。但实验结果由数据背后的规律决定，不由你想要什么结果决定（客观性 + 条件性）。
:::

::: {.box .trap}
**真题陷阱**

- "人们可以根据需要**创造**联系"：**错**。正确的说法是"根据事物固有的联系，**建立新的具体联系**"。
- "人为事物的联系是主观的"：**错**。人造的东西（比如桥、互联网）之间的联系，同样是客观的。
- "事物之间普遍联系，所以任何两个事物之间都直接联系"：**错**。
- 看例子判断是哪个特点：
  - "橘生淮南则为橘，生于淮北则为枳"、"因地制宜"：**条件性**
  - "牵一发而动全身"、"城门失火，殃及池鱼"：**普遍性**
  - "都江堰：顺应水流规律建成水利工程"：**客观性**（依据固有联系建立新联系）
:::

::: {.box .motto}
口诀：**联系不能造，只能顺着搭；处处有联系，未必都直达。**
:::

::: {.box .quiz}
**自测 10-1**　"橘生淮南则为橘，生于淮北则为枳"，主要体现的是联系的（　）\
A. 客观性　B. 普遍性　C. 多样性　D. 条件性

**自测 10-2**　判断：人们可以根据自己的需要创造事物之间的联系。（　）

**自测 10-3**　判断：联系具有普遍性，因此世界上任何两个事物之间都存在直接联系。（　）
:::

## [模糊点]{.tag .fuzzy} 14　主次矛盾与矛盾的主次方面

这个点容易混，是因为两组概念长得太像。先看**范围**：一个说的是"**好几个矛盾**之间谁最重要"，一个说的是"**一个矛盾内部**两方谁占上风"。

| | 主要矛盾 vs 次要矛盾 | 矛盾的主要方面 vs 次要方面 |
|---|---|---|
| 范围 | 复杂事物中有**多个矛盾** | **一个矛盾**内部的两个方面 |
| 谁是"主要" | 处于支配地位、对事物发展起**决定作用**的那个矛盾 | 在矛盾双方中处于**支配地位**、起**主导作用**的那一方 |
| 方法论 | **抓重点**，集中力量解决主要矛盾 | 看问题要**分清主流和支流** |
| 典型说法 | "牵牛要牵牛鼻子"、"抓关键" | "九个指头和一个指头"、"成绩是主流，问题是支流" |

::: {.box .core}
**三句话一定要会：**

1. **事物的性质，主要是由主要矛盾的主要方面决定的。**
2. **两点论和重点论相统一**：两点论是既看主要矛盾，也看次要矛盾，既看主要方面，也看次要方面；重点论是在这当中**着重**把握主要矛盾和矛盾的主要方面。
3. 主次地位**不是固定的**，在一定条件下可以相互转化。
:::

::: {.box .analogy}
**统计类比：主成分分析**

一堆变量里，第一主成分解释的方差最多，它就是"主要矛盾"，分析时先抓它（**重点论**）。但其余主成分也不能直接扔掉，它们也携带信息（**两点论**）。
数据一变，主成分的排序也可能变（**主次可以转化**）。
:::

::: {.box .trap}
**真题陷阱**

- "事物的性质由**主要矛盾**决定"：**不准确**，要说"主要由主要矛盾的**主要方面**决定"。
- "眉毛胡子一把抓"：违背**重点论**，属于均衡论。
- "只抓一点，不及其余"、"一叶障目"：违背**两点论**，属于一点论。
- "弹钢琴"（统筹兼顾，既抓中心工作，又围绕中心安排其他工作）：体现**两点论和重点论的统一**。
- 我国社会主要矛盾的表述是"人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾"，这是**主要矛盾**原理的应用。
:::

::: {.box .motto}
口诀：**多个矛盾比轻重，一个矛盾分主从；两点重点都要有，性质看"主中之主"。**
:::

::: {.box .quiz}
**自测 14-1**　"牵牛要牵牛鼻子"，体现的方法论是（　）\
A. 抓主要矛盾　B. 分清矛盾的主次方面　C. 坚持两点论　D. 具体问题具体分析

**自测 14-2**　"评价一个人要看他的主流"，主要体现的是（　）\
A. 主要矛盾和次要矛盾的关系　B. 矛盾的主要方面和次要方面的关系\
C. 矛盾的同一性和斗争性的关系　D. 矛盾的普遍性和特殊性的关系

**自测 14-3**　判断：事物的性质是由主要矛盾决定的。（　）
:::

## [模糊点]{.tag .fuzzy} 37　社会发展的动力

这个点的关键是：每种动力**前面的定语不一样**，选择题就考你能不能对上号。

| 动力 | 定位 | 要点 |
|---|---|---|
| **社会基本矛盾** | **根本动力** | 生产力和生产关系、经济基础和上层建筑的矛盾。其中生产力和生产关系的矛盾是更为基本的矛盾 |
| **阶级斗争** | **阶级社会**发展的**直接动力** | 只适用于阶级社会，不是一切社会 |
| **社会革命** | 推动社会发展的重要动力 | 根源于社会基本矛盾的尖锐化；结果是社会形态的**根本质变**（新的社会制度代替旧的） |
| **改革** | 社会发展的重要动力 | 在**根本社会制度不变**的前提下，社会形态的**自我完善和发展** |
| **科学技术** | 推动社会发展的重要力量 | 通过影响生产力起作用，深刻改变人们的生产方式、生活方式和思维方式 |

::: {.box .core}
**革命和改革的区别是高频考点：**

- **革命**：改变根本社会制度，是**根本质变**。
- **改革**：不改变根本社会制度，是社会制度的**自我完善**。
- 改革开放被称为"中国的**第二次革命**"，这是从改革的**深刻性和广泛性**来说的，**不是**说它要改变社会主义根本制度。
:::

::: {.box .analogy}
**统计类比：路径图里的中介变量**

社会基本矛盾 →（在阶级社会中表现为）阶级斗争 → 社会发展

社会基本矛盾是最底层的**根本原因**；在阶级社会里，它通过阶级斗争这个"中介变量"表现出来，所以阶级斗争是**直接**动力。没有阶级的社会里这条中介路径就不存在了，但根本原因一直都在。
:::

::: {.box .trap}
**真题陷阱**

- "阶级斗争是**一切社会**发展的直接动力"：**错**，只限于阶级社会。
- "阶级斗争是社会发展的**根本**动力"：**错**，根本动力是社会基本矛盾。
- "改革的实质是改变社会的根本制度"：**错**，那是革命。
- "科学技术是社会发展的根本动力"：**错**，它是重要力量。
:::

::: {.box .motto}
口诀：**根本靠基本矛盾，直接靠阶级斗争（限阶级社会）；革命换制度，改革补制度，科技是杠杆。**
:::

::: {.box .quiz}
**自测 37-1**　社会发展的根本动力是（　）\
A. 阶级斗争　B. 科学技术　C. 社会基本矛盾　D. 改革

**自测 37-2**　判断：改革的实质是改变社会的根本制度。（　）

**自测 37-3**　判断：阶级斗争是一切社会发展的直接动力。（　）
:::

# 第二部分　三星高频点速览

> 你标了熟的三星点，这里只留"核心 + 陷阱"，用来考前快速过一遍。第 10、14 点已经在第一部分详细讲过，这里不重复。

## [高频]{.tag .hot} 4　物质范畴

::: {.box .core}
物质的**唯一特性是客观实在性**：不依赖于人的意识而存在，又能被人的意识所反映。
列宁的定义："物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的，它不依赖于我们的感觉而存在，为我们的感觉所复写、摄影、反映。"
:::

::: {.box .trap}
- 物质的唯一特性是"运动"或"可感知性"：**错**。运动是物质的根本属性（存在方式），不是"唯一特性"。
- 把物质等同于某种具体物质（水、原子）：这是旧唯物主义的错误。哲学上的物质，是对一切具体物质共同特性的抽象。
:::

## [高频]{.tag .hot} 6　主观能动性与客观规律性的统一

::: {.box .core}
- 规律是客观的：人**不能创造、消灭、改变**规律，但可以**认识和利用**规律。
- **尊重客观规律**是正确发挥主观能动性的**前提**；只有充分**发挥主观能动性**，才能正确认识和利用客观规律。
- **实践**是二者统一的**基础**。
:::

::: {.box .trap}
- "人可以改造 / 创造规律"：**错**，这是唯意志论。"揠苗助长"就是违背规律的反面例子。
- "人在规律面前无能为力"：**错**，这是宿命论。"因势利导"、"顺势而为"才是正确做法。
:::

## [高频]{.tag .hot} 12　矛盾的同一性与斗争性

::: {.box .core}
- **同一性**：矛盾双方**相互依存**（一方以另一方为存在前提），**相互贯通**（相互渗透，一定条件下相互转化）。
- **斗争性**：矛盾双方**相互排斥、相互分离**。
- 二者关系：同一性离不开斗争性，斗争性寓于同一性之中，两者相互联结。
- 作用：同一性让双方相互吸收有利因素、规定事物发展的方向；斗争性推动双方力量对比变化，促成质变。
:::

::: {.box .trap}
- "同一性就是两者相同"：**错**。同一性是**对立面之间**的统一，是包含差别的同一。
- "和谐就是没有矛盾"：**错**。和谐是矛盾的一种特殊表现形式。
- "祸兮福之所倚，福兮祸之所伏"体现的是**相互转化**，也就是**同一性**。
:::

## [高频]{.tag .hot} 13　矛盾的普遍性与特殊性

::: {.box .core}
- **普遍性**：矛盾存在于一切事物中，贯穿于每一事物发展过程的始终（事事有矛盾，时时有矛盾）。
- **特殊性**：不同事物的矛盾、同一事物不同阶段的矛盾、矛盾的不同方面，各有各的特点。
- 关系：普遍性寓于特殊性之中（**共性寓于个性**），在一定条件下相互转化。
- 这一关系原理是**关于事物矛盾问题的精髓**，也是马克思主义基本原理同中国具体实际相结合的哲学依据。
- **具体问题具体分析**是马克思主义**活的灵魂**。
:::

::: {.box .analogy}
统计类比：总体均值不能脱离一个个个体单独存在，它就"藏"在个体数据里（共性寓于个性）。但每个个体都有自己的偏差（特殊性）。
:::

::: {.box .trap}
- "白马非马"：把个性和共性割裂开了，**错**。
- "对症下药"、"因材施教"、"量体裁衣"：体现**特殊性 / 具体问题具体分析**。
- "精髓"和"活的灵魂"别混：普遍性和特殊性的关系原理是**精髓**，具体问题具体分析是**活的灵魂**。
:::

## [高频]{.tag .hot} 16　量变质变规律

::: {.box .core}
- **度**：保持事物质的数量界限。量变在度内，越过度就发生质变。
- **量变**：数量增减、场所变更，也包括成分**结构和排列次序**的变化（比如同分异构体）。
- 关系：**量变是质变的必要准备，质变是量变的必然结果**；质变又为新的量变开辟道路。总的量变过程中有部分质变，质变过程中也有量的扩张。
- 方法论：坚持**适度原则**，重视**量的积累**，抓住时机**促成质变**。
:::

::: {.box .analogy}
统计类比：质量控制图。数据在上下控制限之内波动，过程"在控"（量变）；一旦越过控制限，过程就"失控"了（质变）。控制限就是"度"。
:::

::: {.box .trap}
- "量变就是数量的增减"：**不全面**。结构和排列次序的变化也算量变的形式。
- "过犹不及"：体现**度**；"不积跬步，无以至千里"：体现**量的积累**。
:::

## [高频]{.tag .hot} 22　实践对认识的决定作用

::: {.box .core}
实践是认识的**来源、动力、目的**，是检验认识真理性的**唯一标准**。
:::

::: {.box .trap}
- "认识来源于实践"，意思是一切认识**归根到底**来源于实践，**不是**说每个人的每个认识都要亲身实践。书本知识（间接经验）对读者来说是间接经验，但对最初获得它的人来说是直接经验。
- 所以"秀才不出门，全知天下事"讲的是间接经验，并不违背这条原理；"纸上得来终觉浅，绝知此事要躬行"强调的是实践的重要性。
:::

## [高频]{.tag .hot} 24　感性认识与理性认识

::: {.box .core}
| | 感性认识 | 理性认识 |
|---|---|---|
| 形式 | 感觉、知觉、表象 | 概念、判断、推理 |
| 反映什么 | 现象、外部联系 | 本质、内部联系 |

- 理性认识**依赖于**感性认识；感性认识**有待于发展到**理性认识；二者**相互渗透、相互包含**。
- 第一次飞跃的条件：充分可靠的感性材料 + 科学的思维方法（去粗取精、去伪存真、由此及彼、由表及里）。
:::

::: {.box .analogy}
统计类比：感性认识像**描述统计**，看到的是数据的表面样子；理性认识像**统计推断和建模**，抓到的是数据背后的规律。不做描述直接建模会出问题，只做描述永远到不了规律。
:::

::: {.box .trap}
- 只相信理性、贬低感性：**唯理论**，容易变成教条主义。
- 只相信感性、贬低理性：**经验论**，容易变成经验主义。
:::

## [高频]{.tag .hot} 27　真理的绝对性与相对性

::: {.box .core}
- **绝对性**：任何真理都包含不依赖于人的客观内容；人类认识按其本性能够正确认识无限发展的物质世界。
- **相对性**：对特定对象的认识，在**广度**上有限，在**深度**上是近似的。
- 任何真理**都既是绝对的，又是相对的**，二者相互依存、相互包含。
:::

::: {.box .analogy}
统计类比：**置信区间**。它确实包含了关于真实参数的客观信息（绝对性），但只在一定精度和条件下成立（相对性）。样本越大，区间越窄，这就像认识不断深化的过程。
:::

::: {.box .trap}
- 牛顿力学被相对论"推翻"了：**错**。牛顿力学在宏观、低速条件下仍然是真理，相对论只是揭示了它适用的范围。
- 只讲绝对性：**绝对主义**（教条主义）；只讲相对性：**相对主义**（诡辩论）。
:::

## [高频]{.tag .hot} 29　真理的检验标准

::: {.box .core}
- **实践是检验真理的唯一标准**。原因：真理的本性是主观符合客观，而实践具有**直接现实性**，能把主观和客观联系起来加以对照。
- 实践标准**既确定又不确定**：确定性（绝对性）指归根到底只有实践能检验真理；不确定性（相对性）指每一次具体实践都受历史条件限制，不能一次就完全证实或驳倒一切认识。
- **逻辑证明**是检验真理的必要补充，但**不能代替**实践。
:::

::: {.box .analogy}
统计类比：**假设检验**必须用数据（实践），光靠推导（逻辑证明）只能保证"前提成立，结论就成立"。一次检验可能犯第一类或第二类错误（不确定性），但不断重复检验，最终能逼近真相（确定性）。
:::

::: {.box .trap}
- "逻辑证明也是检验真理的标准"：**错**，它只是补充手段。
- "实践标准具有不确定性，所以实践不能检验真理"：**错**。
- "多数人同意的就是真理"、"有用就是真理"（实用主义）：**错**。
:::

## [高频]{.tag .hot} 33　社会存在与社会意识

::: {.box .core}
- **社会存在决定社会意识**，社会意识是社会存在的反映。
- 社会意识有**相对独立性**，具体有五点：
  1. 与社会存在的变化发展**不完全同步**（可能落后，也可能超前）；
  2. 与社会经济的发展水平**不平衡**；
  3. 有**历史继承性**；
  4. 各种社会意识形式之间**相互影响**；
  5. 对社会存在有**能动的反作用**。
:::

::: {.box .trap}
- "社会意识总是和社会存在同步变化"：**错**。
- "经济落后的国家在哲学上仍然能够演奏第一小提琴"：体现**与经济发展水平不平衡**。
- "移风易俗不容易"：体现社会意识的**落后性和历史继承性**。
:::

## [高频]{.tag .hot} 34　生产力与生产关系

::: {.box .core}
- **生产力**：人们解决社会同自然矛盾的实际能力。要素是劳动资料（**生产工具**是生产力发展水平的主要标志）、劳动对象、劳动者；科学技术渗透在各个要素中。
- **生产关系**：人们在物质生产过程中结成的经济关系，其中**生产资料所有制**是基础。
- 规律：**生产力决定生产关系，生产关系反作用于生产力；生产关系一定要适合生产力状况。**
:::

::: {.box .trap}
- "生产关系越先进越好"、"公有化程度越高越好"：**错**。生产关系超越生产力发展阶段，同样会阻碍生产力发展。适合才是好的。
- 改革在经济上的含义，就是调整不适应生产力发展的那部分生产关系。
:::

## [高频]{.tag .hot} 38　人民群众是历史的创造者

::: {.box .core}
- **群众史观**：人民群众是历史的创造者。人民群众是**物质财富**的创造者、**精神财富**的创造者、**社会变革的决定力量**。
- 人民群众创造历史的活动，受到经济、政治、精神文化条件的**制约**。
- **英雄史观**（唯心史观）：认为杰出人物、帝王将相决定历史。
- 党的群众路线：一切为了群众，一切依靠群众，从群众中来，到群众中去。
:::

::: {.box .trap}
- "人民群众可以随心所欲地创造历史"：**错**，要受历史条件制约。
- "杰出人物可以改变历史发展的总趋势"：**错**。他们能加速或延缓历史进程，但改变不了总趋势。
:::
